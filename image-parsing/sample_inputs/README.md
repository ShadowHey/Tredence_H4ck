# Sample Inputs for ShelfSense AI Image Parsing

This folder contains raw supermarket shelf photographs used as genuine inference inputs for the image-parsing pipeline.

## Files
1. `test_987.jpg`:
   - Raw coffee/cereal retail gondola photograph (3264 × 2448 / 1024 × 768 resized).
   - Shows stacked coffee cans, bags, cereal boxes, and clear empty gaps on the middle shelves.
2. `test_999 (1).jpg`:
   - Raw pharmacy/digestive health supermarket shelf photograph (1024 × 768).
   - Shows medicine packs, bottles, and distinct empty shelf slots.
3. `test_image.jpg`:
   - Reference 7-tier shelf unit from `K-saif/Empty-Shelf-Alert-System` (1150 × 2048).

> **Important**: Original image files must never be overwritten by annotated versions. All outputs are written to the `outputs/` directory.
